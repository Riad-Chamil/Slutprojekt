Websidan om Idrott och hälsa 1 kursen är ett websida som hjälper dig genom att ha allt information man skulle behöva för, under och vid slutet av kursen.
Du kan hitta allt du skulle behöva som Boken, Matrisen, skolverket och ett exempel inom en av det viktigaste saker i idrott och hälsa.

Boken: I websidan Boken.html så kan du hitta Idrott och hälsa 1 boken och det kan du
använda för att plugga och få informationen som du behöver i vardags livet och provet.

Matrisen: I websidan Matris.html så kan du hitta Idrott och hälsa 1 Matrisen och det kan du
använda för att få veta vad du skulle behöva nå göra göra för att nå några specifika betyg inom kursen.

skolverket: I websidan Skolverket.html så kan du hitta Skolverket.se websidan och det kan du
använda för att få veta allt som gäller när det kommer till idrott och hälsa.

Exempel: I websidan Exempel.html så kan du hitta ett exempel på en av det viktigase saker som man kommer att gå genom i idrott och hälsa och det är om lungorna.

Jag har alla saker organiserad och i plats som gör att det är enkel att hitta.

Det finns också dokumentaion som gör så att det är enkel att förstår allt koder.

Websidan är anpassad också för mobiler.

Websidan har XSS attack skydd i Exempel sida.

JavaScript är i sitt egen fil som gör koden mer organiserad, lättare att hitta saker och html renare.

Jag använde mig att Prettier för att hitta fel och organisera websidan för läsare.

Det finns också ett navigation bar så att man kan gå genom allt som finns och hitta saker.
